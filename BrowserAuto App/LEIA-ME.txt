╔══════════════════════════════════════════════════════╗
║          BroserAuto Web v2.0                          ║
║   Automacao de Navegador com Interface Web            ║
║   Backend: Python 3 ou Node.js                        ║
╚══════════════════════════════════════════════════════╝

COMO USAR:
  1. Execute "Browser_Auto.exe" para extrair os arquivos
  2. Na pasta extraida, execute:

     >>> launcher_app.vbs       (recomendado — sem janela de terminal)
     >>> launcher_debug.bat     (mostra terminal)
     >>> launcher_script.ps1    (PowerShell colorido)
     >>> node server.js         (manual)
     >>> py -3 main.py          (manual via Python)

  3. O servidor inicia e abre o navegador na interface web
  4. Para encerrar, clique em "Sair do App" na interface web

FUNCOES:
  - Abrir Navegador: abre o site no navegador escolhido
  - Fechar Navegador: encerra o navegador
  - Screenshot: tira foto da tela
  - Rolar para Baixo/Cima: rola a pagina automaticamente
  - Digitar Texto: digita texto onde voce clicar
  - Abrir URL no Site Atual: abre outro link sem fechar

ARQUIVOS EXTRAIDOS:
  launcher_app.vbs      - [RECOMENDADO] Inicia sem janela de terminal
  launcher_debug.bat    - Inicia mostrando o terminal (CMD)
  launcher_script.ps1   - Inicia via PowerShell colorido
  main.py               - Backend em Python 3 (stdlib)
  server.js             - Backend em Node.js (stdlib)
  renderer/             - Interface web (HTML + CSS + JS)

REQUISITOS:
  - Node.js 18+ OU Python 3.x
  - Windows (para automacao via PowerShell)

NOTA:
  - Screenshots salvos em: Imagens/BroserAuto Screenshots
  - Para editar o codigo, edite os arquivos extraidos
  - Use "Sair do App" na web para encerrar o servidor
  - Para configurar os navegadores, edite main.py ou server.js
    e substitua "CAMINHO_DO_SEU_NAVEGADOR" pelo caminho real
